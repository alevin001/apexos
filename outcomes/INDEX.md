# Outcome Registry

Human-readable index of outcome layer artifacts. Update this file when creating, completing, reviewing, validating, promoting learning, or archiving outcome content.

**Last updated:** Build 07 initial scaffold

## How to Use

1. Add an entry when receiving a Recommendation Package and observed outcome.
2. Link to Recommendation Package, component artifacts, and Validation Package paths.
3. Mark status: `draft`, `in_progress`, `complete`, `under_review`, `validated`, or `archived`.
4. Do not duplicate content here — this is an index only.
