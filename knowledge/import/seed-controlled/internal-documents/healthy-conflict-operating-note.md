# Healthy Conflict Operating Note

Source type: internal operating document (controlled Build 18 seed).

## Intent

Use healthy conflict to surface misalignment early, especially when execution speed and product/sales priorities diverge.

## Guidance

1. Name the conflict points without personalizing.
2. Separate evidence from interpretation.
3. Decide the one conversation that must happen next.
4. Capture the decision and expected outcome for later validation.

## Non-claims

This note is executive material for retrieval practice. It is not doctrine and does not amend the Charter.
