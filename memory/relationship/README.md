# Relationship Memory

## Responsibility

Tracks the evolution of leadership relationships over time. This is one of the highest-value memory categories because leadership occurs within relationships (LAD-003, AF-001).

## Architecture Reference

- **Primary:** `architecture/3 - ApexOS - Memory Architecture v1.0.docx` (Relationship Memory)
- **Foundations:** `architecture/2 - ApexOS - Foundations Architecture v1.0.docx` (Relationship object, Relationship Principle)

## Contents Include

Trust, alignment, influence effectiveness, communication effectiveness, recurring friction, recurring success patterns, motivational drivers, resistance patterns.
