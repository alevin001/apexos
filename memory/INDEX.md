# Memory Registry

Human-readable index of memory layer artifacts. Update this file when creating, promoting, weakening, or retiring memory content.

**Last updated:** Build 03 initial scaffold

## How to Use

1. Add an entry when creating an observation, memory artifact, pattern, or promotion record.
2. Link to the artifact path and its originating knowledge or observation.
3. Mark status: `draft`, `active`, `under_review`, `weakened`, or `retired`.
4. Do not duplicate content here — this is an index only.
