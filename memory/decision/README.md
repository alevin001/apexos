# Decision Memory

## Responsibility

Remembers what choices were made and why. Decisions provide the causal link between situations and outcomes/results.

## Architecture Reference

- **Primary:** `architecture/3 - ApexOS - Memory Architecture v1.0.docx` (Decision Memory)
- **Foundations:** `architecture/2 - ApexOS - Foundations Architecture v1.0.docx` (Decision object)

## Contents Include

Decisions made, decision rationale, resulting outcomes.

## High-Value Evidence

Action-to-outcome correlation (Recommendation → Decision → Action → Outcome) is high-value evidence (LAD-016, AF-017). Link outcomes via `workflows/link-outcome-reference.md`.
