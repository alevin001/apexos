# Tradeoffs

## Responsibility

Explicitly identify tradeoffs in executive decisions — making costs, benefits, risks, and competing priorities visible.

## Architecture Reference

- **Primary:** `architecture/8 - ApexOS - Recommendation Architecture v1.0.docx` (Tradeoff Analysis)

## Examples

Short-term gain versus long-term gain, speed versus relationship preservation, certainty versus flexibility, execution versus buy-in, accountability versus autonomy.

## Principle

The purpose is not to eliminate tradeoffs. The purpose is to make tradeoffs visible.
