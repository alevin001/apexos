# Recommendations

## Responsibility

Generate primary and alternative recommendations evaluated against Charter doctrine, evidence, and historical learning.

## Architecture Reference

- **Primary:** `architecture/8 - ApexOS - Recommendation Architecture v1.0.docx` (Option Generation, Doctrine Evaluation, Outcome-Validated Recommendation Principle)

## Output Elements

Primary recommendation, alternative recommendations, doctrine alignment assessment, supporting evidence, supporting findings, confidence assessment.

## Doctrine Alignment

Recommendations should strengthen trust, alignment, communication effectiveness, leadership effectiveness, understanding, strategic clarity, and measurable outcomes/results.

## Cause-And-Effect Transparency

Recommendations must explain expected benefits, expected risks, supporting evidence, underlying assumptions, expected consequences, and confidence — not simply state "Do X."
