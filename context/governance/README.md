# Context Governance

Layer-specific governance artifacts for the Context Layer. Cross-layer controls also apply via `governance/source-fidelity/context-layer.md`.

## Artifacts

| Artifact | Purpose |
|----------|---------|
| `context-fidelity-checklist.md` | Pre-handoff validation of context artifacts |
| `context-drift-detection.md` | Indicators and responses for context drift |
| `architecture-mapping.md` | Maps Context Architecture to implementation artifacts |

## Usage

Run the fidelity checklist before every retrieval handoff. Monitor drift indicators during context review. Use architecture mapping for traceability audits.

| Control | Location |
|---------|----------|
| Context-specific fidelity | This folder + `governance/source-fidelity/context-layer.md` |
| Cross-layer traceability | `governance/traceability/README.md` |
| Review controls | `governance/review-controls/README.md` |
