# Organizational Context

## Responsibility

Understand the current state of the organization — collective conditions that may not be visible through individual relationships alone.

## Architecture Reference

- **Primary:** `architecture/4 - ApexOS - Context Architecture v1.0.docx` (Organizational Context)

## Contents Include

Organizational sentiment, morale, engagement, cultural health, organizational alignment, change readiness, organizational pressures.

## Build Plan Note

The Build Plan lists "Organizational memory" under the Memory Layer. Memory Architecture v1.0 does not define Organizational Memory as a separate category. Organizational conditions are addressed here as context. Refer to `memory/README.md` for the clarification note.
