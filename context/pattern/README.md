# Pattern Context

## Responsibility

Provide access to validated learning during context evaluation.

## Architecture Reference

- **Primary:** `architecture/4 - ApexOS - Context Architecture v1.0.docx` (Pattern Context)

## Contents Include

Communication patterns, leadership patterns, influence patterns, relationship patterns, organizational patterns.

## Principle

Patterns represent validated observations supported by evidence. Patterns inform guidance but do not determine truth (CP-009).
