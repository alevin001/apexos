# Executive Context

## Responsibility

Understand the current state of the executive. The executive is part of the situation and must be evaluated accordingly.

## Architecture Reference

- **Primary:** `architecture/4 - ApexOS - Context Architecture v1.0.docx` (Executive Context)

## Contents Include

Emotional state, stress level, confidence level, energy level, overwhelm level, current priorities, current concerns.

## Architectural Finding

Executive state influences communication, decision-making, influence, leadership effectiveness, and outcomes.
