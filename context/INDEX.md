# Context Registry

Human-readable index of context layer artifacts. Update this file when creating, handing off to retrieval, reviewing, or archiving context evaluations.

**Last updated:** Build 04 initial scaffold

## How to Use

1. Add an entry when creating a situation intake or context evaluation.
2. Link to the artifact path and related memory or knowledge references.
3. Mark status: `draft`, `active`, `under_review`, `handed_off`, or `archived`.
4. Do not duplicate content here — this is an index only.
