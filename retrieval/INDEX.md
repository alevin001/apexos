## How to Use

1. Add an entry when creating a retrieval request.
2. Link to context reference, evidence package, and Context Package paths.
3. Mark status: `draft`, `in_progress`, `assembled`, `delivered`, `validated`, or `archived`.
4. Do not duplicate content here — this is an index only.
