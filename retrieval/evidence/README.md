# Evidence Retrieval

## Responsibility

Assemble evidence for interpretation — supporting evidence, contradictory evidence, alternative perspectives, and competing interpretations.

## Architecture Reference

- **Primary:** `architecture/5 - ApexOS - Retrieval Architecture v1.0.docx` (Evidence Assembly Principle, Contradictory Evidence Principle)

## Purpose

Reduce confirmation bias, executive blind spots, organizational blind spots, and system drift by systematically assembling relevant evidence before inference.

## Evidence First Principle

Retrieval should maximize evidence quality before inference occurs (LAD-008).
