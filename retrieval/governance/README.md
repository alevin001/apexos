# Retrieval Governance

Layer-specific governance artifacts for the Retrieval Layer. Cross-layer controls also apply via `governance/source-fidelity/retrieval-layer.md`.

## Artifacts

| Artifact | Purpose |
|----------|---------|
| `evidence-first-checklist.md` | Pre-assembly validation — evidence before inference |
| `retrieval-fidelity-checklist.md` | Pre-delivery validation of assembled packages |
| `architecture-mapping.md` | Maps Retrieval Architecture to implementation artifacts |

## Usage

Run the evidence-first checklist before evidence assembly. Run the retrieval fidelity checklist before Context Package delivery. Use architecture mapping for traceability audits.

| Control | Location |
|---------|----------|
| Retrieval-specific fidelity | This folder + `governance/source-fidelity/retrieval-layer.md` |
| Cross-layer traceability | `governance/traceability/README.md` |
| Review controls | `governance/review-controls/README.md` |
