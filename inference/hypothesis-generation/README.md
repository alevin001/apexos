# Hypothesis Generation

## Responsibility

Generates plausible explanations not yet proven — root-cause, behavioral, organizational, relationship, and strategic hypotheses.

## Architecture Reference

- **Primary:** `architecture/7 - ApexOS - Inference Architecture v1.0.docx` (Hypothesis Generation, Inferential Transparency Principle)

## Build 05 Conventions

| Convention | Value |
|------------|-------|
| Template | `templates/hypothesis-evaluation-template.md` |
| Naming | `inf-hyp-{short-slug}.md` |
| ID prefix | `INF-HYP-` |
| Workflow | Part of `workflows/interpretation-workflow.md` |

## Category Rule

Hypotheses are not evidence. Hypotheses are not findings. Hypotheses are not conclusions.

## Hypothesis Types

| Type | Description |
|------|-------------|
| Root-cause | Underlying cause explanations |
| Behavioral | Individual behavior explanations |
| Organizational | Organizational dynamic explanations |
| Relationship | Relationship dynamic explanations |
| Strategic | Strategic alignment or direction explanations |

## Uncertainty Handling

When evidence is incomplete, contradictory, or insufficient, ApexOS may conclude that more evidence is required or confidence is insufficient (AF-013). Uncertainty is a valid output.

## Evaluative Questions

- What explanation best fits the available evidence?
- What alternative explanations exist?
- What evidence would strengthen the hypothesis?
- What evidence would invalidate the hypothesis?
