# Hypothesis Generation

## Responsibility

Generates plausible explanations not yet proven — root-cause, behavioral, organizational, relationship, and strategic hypotheses.

## Architecture Reference

- **Primary:** `architecture/7 - ApexOS - Inference Architecture v1.0.docx` (Hypothesis Generation, Inferential Transparency Principle)

## Category Rule

Hypotheses are not evidence. Hypotheses are not findings. Hypotheses are not conclusions.

## Uncertainty Handling

When evidence is incomplete, contradictory, or insufficient, ApexOS may conclude that more evidence is required or confidence is insufficient (AF-013). Uncertainty is a valid output.
