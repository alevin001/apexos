# Pattern Recognition

## Responsibility

Evaluates patterns within inferential analysis — identifying recurring observations, validated learning, and pattern strength during evidence interpretation.

## Architecture Reference

- **Primary:** `architecture/7 - ApexOS - Inference Architecture v1.0.docx` (Evidence Evaluation — pattern strength weighting)
- **Build Plan:** `build/ApexOS V1 Build Plan.txt` (Pattern recognition)

## Build 05 Conventions

Pattern recognition is an inferential process applied during evidence evaluation — not a separate artifact category. Pattern strength weighting occurs within `templates/evidence-assessment-template.md` and `workflows/evidence-evaluation-workflow.md`.

## Distinction from Pattern Memory

| Concept | Location | Role |
|---------|----------|------|
| Pattern memory | `memory/pattern/` | Stored validated learning |
| Pattern context | `context/pattern/` | Relevance of patterns to current situation |
| Pattern retrieval | `retrieval/pattern/` | Retrieval of validated patterns |
| Pattern recognition | `inference/pattern-recognition/` | Inferential evaluation of pattern evidence |

Pattern **validation** occurs in `outcomes/`. Pattern **recognition** here evaluates pattern evidence within interpretation.

## Weighting

Evidence may be weighted according to:

- Pattern strength
- Outcome/results validation
- Repetition of observation
- Strategic significance
- Relationship significance
- Source credibility

See `workflows/evidence-evaluation-workflow.md` step 4 (Apply evidence weighting).

## Do Not Store Here

- Pattern memory artifacts (see `memory/pattern/`)
- Pattern validation records (see `outcomes/`)
- Standalone pattern artifacts — weighting occurs in evidence assessment
