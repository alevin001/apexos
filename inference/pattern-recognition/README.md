# Pattern Recognition

## Responsibility

Evaluates patterns within inferential analysis — identifying recurring observations, validated learning, and pattern strength during evidence interpretation.

## Architecture Reference

- **Primary:** `architecture/7 - ApexOS - Inference Architecture v1.0.docx` (Evidence Evaluation — pattern strength weighting)
- **Build Plan:** `build/ApexOS V1 Build Plan.txt` (Pattern recognition)

## Distinction from Pattern Memory

Pattern recognition here is an **inferential process** applied to assembled evidence. Pattern **memory** is stored in `memory/pattern/`. Pattern **validation** occurs in `outcomes/`.

## Weighting

Evidence may be weighted according to pattern strength, outcome/results validation, repetition of observation, strategic significance, relationship significance, and source credibility.
