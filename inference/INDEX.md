# Inference Registry

Human-readable index of inference layer artifacts. Update this file when creating, completing, reviewing, handing off to recommendation, or archiving inference content.

**Last updated:** Build 05 initial scaffold

## How to Use

1. Add an entry when receiving a Context Package from retrieval.
2. Link to Context Package, component artifacts, and Interpretation Package paths.
3. Mark status: `draft`, `in_progress`, `complete`, `under_review`, `handed_off`, or `archived`.
4. Do not duplicate content here — this is an index only.
