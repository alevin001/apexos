# Options

## Responsibility

Generate multiple viable options whenever practical to support executive judgment through comparison and evaluation.

## Architecture Reference

- **Primary:** `architecture/8 - ApexOS - Recommendation Architecture v1.0.docx` (Option Generation, Alternative Courses Of Action)
- **Template:** `templates/option-generation-template.md`
- **Workflow:** `workflows/option-generation-workflow.md`

## Option Types

Communication options, leadership options, organizational options, relationship options, strategic options, operational options.

## Naming Convention

`rec-opt-{short-slug}.md` — see `REPOSITORY-GUIDE.md`

## Principle

The purpose is not to force a single path. The purpose is to support executive judgment through informed comparison.
