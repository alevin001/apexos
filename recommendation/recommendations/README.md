# Recommendations

## Responsibility

Generate primary and alternative recommendations evaluated against Charter doctrine, evidence, and historical learning. Store doctrine evaluation, risk assessment, and opportunity assessment artifacts.

## Architecture Reference

- **Primary:** `architecture/8 - ApexOS - Recommendation Architecture v1.0.docx` (Option Generation, Doctrine Evaluation, Outcome-Validated Recommendation Principle)
- **Templates:** `templates/doctrine-evaluation-template.md`, `templates/risk-assessment-template.md`, `templates/opportunity-assessment-template.md`
- **Workflows:** `workflows/doctrine-evaluation-workflow.md`, `workflows/recommendation-workflow.md`

## Output Elements

Primary recommendation, alternative recommendations, doctrine alignment assessment, supporting evidence, supporting findings, confidence assessment.

## Naming Conventions

| Artifact | Pattern |
|----------|---------|
| Doctrine evaluation | `rec-doc-{short-slug}.md` |
| Risk assessment | `rec-rsk-{short-slug}.md` |
| Opportunity assessment | `rec-opp-{short-slug}.md` |

See `REPOSITORY-GUIDE.md`.

## Doctrine Alignment

Recommendations should strengthen trust, alignment, communication effectiveness, leadership effectiveness, understanding, strategic clarity, and measurable outcomes/results.

## Cause-And-Effect Transparency

Recommendations must explain expected benefits, expected risks, supporting evidence, underlying assumptions, expected consequences, and confidence — not simply state "Do X."
