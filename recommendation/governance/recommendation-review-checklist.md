# Recommendation Review Checklist

Pre-delivery validation checklist for Recommendation Packages and component artifacts.

## Architecture Reference

- Recommendation Architecture v1.0 (DOC-008) — Recommendation Outputs, Governance Controls, Cause-And-Effect Transparency Principle
- Governance Architecture v1.0 (DOC-006) — LAD-009, LAD-011, LAD-014, LAD-015
- AF-014 — Executive agency preserved

## Inference Handoff Foundation

- [ ] Interpretation Package linked and inference review passed
- [ ] Recommendation operates upon Interpretation Package — not pre-interpretation speculation
- [ ] Synthesized interpretation referenced — not re-derived
- [ ] Findings referenced from Interpretation Package — not re-inferred
- [ ] No recommendations found in Interpretation Package contamination check passed

## Objective Alignment

- [ ] Desired outcome clarified
- [ ] Problem, opportunity, strategic, relationship, and organizational objectives addressed where applicable
- [ ] Recommendations aligned with desired outcomes — not isolated actions
- [ ] No re-interpretation of evidence in objective alignment

## Option Generation

- [ ] Multiple viable options generated when practical
- [ ] Primary recommendation candidate identified with rationale
- [ ] Alternative recommendation candidates documented
- [ ] Options supported by Interpretation Package — not re-inferred
- [ ] Option types addressed (communication, leadership, organizational, relationship, strategic, operational)

## Doctrine Evaluation

- [ ] Each option evaluated against Charter doctrine
- [ ] Trust, alignment, communication, leadership, understanding, strategic clarity, and outcomes assessed
- [ ] Doctrine references linked — not duplicated
- [ ] Doctrine conflicts documented transparently
- [ ] Doctrine impact on confidence documented

## Risk Evaluation

- [ ] Action-level risks identified for each option
- [ ] Inference risks referenced — action implications evaluated
- [ ] Evidence support referenced — not duplicated or reinterpreted
- [ ] Assumptions influencing risks documented
- [ ] Severity and likelihood assessed

## Opportunity Evaluation

- [ ] Action-level opportunities identified for each option
- [ ] Inference opportunities referenced — action implications evaluated
- [ ] Evidence support referenced — not duplicated or reinterpreted
- [ ] Assumptions influencing opportunities documented
- [ ] Significance assessed

## Tradeoff Analysis

- [ ] Tradeoffs explicitly identified
- [ ] Benefits, costs, risks, opportunities, and competing priorities documented
- [ ] Unresolvable tradeoffs flagged for executive
- [ ] Tradeoffs made visible — not eliminated or hidden

## Cause-And-Effect Transparency

- [ ] Expected benefits explained — not just "Do X"
- [ ] Expected risks explained
- [ ] Supporting evidence referenced
- [ ] Underlying assumptions identified
- [ ] Expected consequences documented
- [ ] Confidence explained with rationale

## Recommendation Confidence

- [ ] Recommendation confidence evaluated independently from inference confidence
- [ ] Confidence influencing factors assessed
- [ ] Per-option confidence documented with rationale
- [ ] Outcome-validated confidence applied where applicable
- [ ] Insufficient information declared if applicable
- [ ] No confidence overstated for persuasive effect

## Category Separation

- [ ] Evidence referenced — not duplicated or reinterpreted
- [ ] Findings referenced from Interpretation Package — not re-inferred
- [ ] Assumptions distinguished from evidence and findings
- [ ] Recommendations distinguished from findings and decisions
- [ ] Unknowns referenced where applicable

## Recommendation Package Completeness

- [ ] Objective assessment populated
- [ ] Primary recommendation documented
- [ ] Alternative recommendations documented
- [ ] Doctrine alignment assessment populated
- [ ] Risk assessment populated
- [ ] Opportunity assessment populated
- [ ] Tradeoff analysis populated
- [ ] Supporting evidence and findings referenced
- [ ] Assumptions documented
- [ ] Confidence assessment populated
- [ ] Expected consequences documented
- [ ] Uncertainty assessment populated (or N/A documented)
- [ ] Outcome tracking considerations identified
- [ ] Executive decision support summary populated
- [ ] All component artifacts linked in frontmatter

## Boundary Compliance

- [ ] No inference re-performed in recommendation artifacts
- [ ] No evidence reinterpretation
- [ ] No outcome validation performed
- [ ] No executive decisions recorded
- [ ] Executive agency preserved — decision-support language only

## Traceability

- [ ] Interpretation Package linked
- [ ] Context Package linked
- [ ] Retrieval request linked
- [ ] Context reference linked
- [ ] Component artifacts linked
- [ ] All artifacts registered in `recommendation/INDEX.md`

## Failure Response

If any item fails:

1. Do not deliver Recommendation Package to executive
2. Re-run failed workflow (doctrine evaluation, tradeoff analysis, etc.)
3. Return to inference if inference gap detected — do not re-infer in recommendation
4. Reclassify content if category violation detected
5. Document in recommendation review artifact
6. Re-run checklist after correction
