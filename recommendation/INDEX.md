## How to Use

1. Add an entry when receiving an Interpretation Package from inference.
2. Link to Interpretation Package, component artifacts, and Recommendation Package paths.
3. Mark status: `draft`, `in_progress`, `complete`, `under_review`, `delivered`, or `archived`.
4. Do not duplicate content here — this is an index only.
